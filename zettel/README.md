# Zettelkasten

Atomic notes — one concept per note, linked to others. Not summaries. Not outlines. Single ideas that stand alone and connect outward.

**The rule:** if a note needs more than one core idea, split it.

---

## How to Add a Note

1. Copy `_templates/zettel.md`
2. Name it: `YYYYMMDD-short-concept-name.md`
3. Write one idea, link to related notes, flag Anki cards
