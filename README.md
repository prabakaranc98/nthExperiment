# The Nth Experiment — 8-Month Self-Directed Diploma

8 months. 2 tracks. 6 subjects. Curiosity-led, experiment-driven, intentional.

---

## What This Is

This is a personal, autodidactic curriculum — a self-directed diploma built not for credentials, not for an audience, but for genuine understanding.

Autodidacticism is the practice of learning on your own terms: following curiosity instead of syllabi, going deep instead of broad, and taking full ownership of what you learn and why. It is not unstructured — it is *self-structured*. The discipline comes from within: from honest questions, from designing experiments, from sitting with confusion, and from reflecting before moving on.

This curriculum exists because the most important things I want to understand don't fit neatly into any course, degree, or program. They sit at intersections — between philosophy and AI, between history and systems, between how the mind works and how markets work. The only way to learn them is to design the path myself.

**The format is simple:** pick a question you genuinely can't stop thinking about, design a small experiment to explore it, do the work, reflect, repeat. No grades. No external validation. Just the compounding of real understanding over 8 months.

## How It Works

1. Pick a subject → define a **tiny experiment** with a clear hypothesis
2. Copy `_templates/experiment.md` → `subjects/0X.../experiments/0N-name/`
3. Log entries (as needed) using `_templates/log-entry.md` → append to `log.md`
4. When done: fill `reflection.md`, update the experiment log table in the subject README
5. The reflection seeds the next experiment
6. Weekly: fill `reviews/week-NN.md`, update `program.md` table
