# Sub-Zero Scratch

Things being built from absolute zero. No prior knowledge assumed. No shortcuts. Everything here is learned by *doing* — not reading about doing.

The eight areas below are not subjects in the main curriculum. They are orthogonal to it: lenses that sharpen the curriculum, crafts that make it legible and shippable, background operations that convert the work into real outcomes, and one artistic outlet that keeps the creative brain fed.

**The rule here:** you don't understand something until you've built it. Not a summary. Not a tutorial walkthrough. Built it, broken it, rebuilt it differently.
