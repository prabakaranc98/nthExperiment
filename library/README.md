# Library

A beginner-friendly, revision-ready reference. Every concept explained from scratch — no assumed knowledge, no hand-waving. Written to be read alongside the seminars, not instead of them.

**FAIRE context:** → [Program Handbook](../faire-program.md) · [FAIRE 501](../faire-program.md) (foundations) · [FAIRE 502](../faire-program.md) (DL) · [FAIRE 504](../faire-program.md) (RL/alignment) · [FAIRE 505](../faire-program.md) (systems)

**Three uses:**
- **First exposure** — new to a topic, need the foundation before reading a paper
- **Revision** — know it but want a clean refresher before building
- **Fresh learning** — coming back after a break, need to reconstruct the intuition fast

## How to use this

- Open a section before reading a related paper in the seminars
- Use revision sheets before starting a build in the 30-build roadmap
- If something in a lecture (lecture-myself/) isn't clicking, come here first

**The standard here:** if a concept can't be explained clearly to a smart person who hasn't seen it before, it isn't explained well enough yet. Every note in this library is held to that standard.
