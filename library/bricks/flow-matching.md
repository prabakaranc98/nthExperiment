# Flow Matching

**One-liner:** Simulation-free training of continuous normalizing flows by regressing a velocity field that transports noise to data along a prescribed probability path; subsumes diffusion as a special case and powers most 2024-2026 frontier image/video/audio generators.

## The formula / definition

Define a probability path p_t(x) from p_0 = N(0,I) to p_1 = data, generated by a velocity field u_t(x) via the continuity (transport) equation ∂_t p_t + ∇·(p_t u_t) = 0. Sampling = integrating the ODE dx/dt = u_t(x) from t=0 to t=1.

Regressing u_t directly is intractable (it's a marginal). **Conditional Flow Matching (CFM)** fixes this: condition on a data point x_1, use a tractable conditional path p_t(x|x_1) with known conditional field u_t(x|x_1), and regress against it:

  L_CFM = E_{t~U[0,1], x_1~data, x~p_t(·|x_1)} ‖ v_θ(t,x) − u_t(x|x_1) ‖²

Key theorem (Lipman et al., 2023): ∇_θ L_CFM = ∇_θ L_FM — the conditional loss has the same gradient as the intractable marginal loss.

**Rectified Flow / linear (OT) path** — the dominant choice: x_t = (1−t)·x_0 + t·x_1 with x_0~N(0,I), giving the constant target u_t(x|x_1) = x_1 − x_0. So you literally regress the straight-line direction from noise to data.

## Where it appears

- **Stable Diffusion 3 / FLUX** — rectified-flow transformers; the de facto image-gen objective post-2024
- **Meta Movie Gen, MovieGen-style video models** — flow matching over spatiotemporal latents
- **Voicebox / Audiobox, F5-TTS** — speech/audio synthesis via conditional FM
- **Llama 3 image stack, Lumina, Stable Audio** — same recipe across modalities
- **Reflow / consistency-style distillation** — straighten paths to enable 1-4 step sampling

## Common mistake

Thinking flow matching is a fundamentally different model from diffusion. With the right path it *is* diffusion — DDPM's score-matching objective corresponds to a particular (variance-preserving, curved) probability path. FM's advantage is the freedom to pick *straight* (OT) paths, which need far fewer ODE steps to integrate. Also: you do NOT integrate the ODE during training (it's simulation-free); integration only happens at sampling time.
