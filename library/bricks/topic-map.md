## Transformer Architecture
| Status | Concept | One-liner | Tier | Brick |
|--------|---------|-----------|:----:|-------|
| ✅ | **Scaled Dot-Product Attention** | Softmax(QKᵀ/√dₖ)V maps queries against keys to produce a value-weighted average, with √dₖ scaling keeping logits in the softmax's non-saturating regime; O(n²d) FLOPs and O(n²) KV reads. | F | `scaled-dot-product-attention.md` |
| ✅ | **Multi-Head Attention** | Run h attention ops in parallel on projected d/h-dim subspaces and concatenate, letting heads specialize on different relations; the head is the unit of interpretability and KV-reduction. | F | `multi-head-attention.md` |
| ✅ | **GQA / MQA** | Grouped-Query (g shared K/V groups) and Multi-Query (one shared K/V head) attention shrink the KV cache by giving many query heads fewer key/value heads at modest quality cost; GQA is the default in modern decoders. | F | `gqa.md` |
| ✅ | **Multi-Head Latent Attention (MLA)** | Compress K/V into a low-rank latent vector cached per token (RoPE applied on a decoupled small key portion), slashing KV memory below GQA while preserving multi-head expressivity (DeepSeek-V2/V3). | C | `multi-head-latent-attention.md` |
| ✅ | **RoPE (Rotary Positional Embeddings)** | Encode position by rotating Q and K in 2D coordinate pairs by a position-dependent angle, so attention logits depend only on relative offset while remaining a pure dot product. | F | `rope.md` |
| ✅ | **RoPE Context Extension (NTK / YaRN / Position Interpolation)** | Extend a RoPE model's usable context by rescaling rotation frequencies — linear interpolation, NTK-aware base scaling, and YaRN's per-frequency wavelength interpolation plus attention-temperature correction. | C | `rope-context-extension.md` |
| ✅ | **NoPE / Positional-Scheme Length Generalization** | Decoder-only models can length-extrapolate with no explicit positional encoding (the causal mask supplies order), reframing positional design as a generalization choice rather than a necessity. | E | `nope-positional-scheme-length-generalization.md` |
| ✅ | **Pre-Norm vs Post-Norm vs Sandwich Norm** | Whether the normalizer sits inside the residual branch (pre-norm, stable deep training), after the addition (post-norm, better-conditioned but needs warmup), or both; the central depth-stability lever. | F | `pre-norm-vs-post-norm-vs-sandwich-norm.md` |
| ✅ | **RMSNorm** | Normalize activations by root-mean-square only (no mean subtraction, often no bias), a cheaper LayerNorm variant that matches quality and is now the default normalizer in most LMs. | F | `rmsnorm.md` |
| ✅ | **QK-Normalization** | Normalize queries and keys before the dot product to bound attention-logit magnitude, preventing training-instability spikes and attention-entropy collapse at scale. | C | `qk-normalization.md` |
| ✅ | **Residual Stream** | The additive skip-connection backbone viewed as a shared linear communication channel every block reads from and writes to; the foundation of mechanistic interpretability and pre-norm reasoning. | F | `residual-stream.md` |
| ✅ | **SwiGLU / GeGLU** | Gated MLP variants replacing the two-matrix FFN with a Swish/GELU gate × value branch (three weight matrices, ~2/3 hidden-dim convention), improving quality per parameter; the default FFN block. | F | `swiglu-geglu.md` |
| ✅ | **Attention Sinks** | Models dump excess attention mass onto the first token(s); preserving these sinks (or adding learned sink/register tokens) enables stable streaming and KV-cache eviction. | C | `attention-sinks.md` |
| ✅ | **Sliding-Window / Local Attention** | Restrict each token to a fixed window of w recent tokens for O(n·w) cost and bounded KV, while stacked layers expand the effective receptive field (Mistral, Gemma interleaved local/global). | F | `sliding-window-local-attention.md` |
| ✅ | **Mixture-of-Experts (MoE) FFN** | Replace the dense FFN with many expert MLPs and a router sending each token to a top-k subset, decoupling total parameters from per-token compute; the dominant frontier scaling strategy. | C | `moe-routing.md` |
| ✅ | **Expert Load Balancing** | Auxiliary load-balancing losses (or aux-loss-free bias adjustment) plus capacity-factor/token-dropping tuning that prevent MoE routers from collapsing onto a few experts. | C | `expert-load-balancing.md` |
| ✅ | **GELU / SiLU (Smooth Activations)** | The smooth nonlinearities actually used in transformers/FFNs; the list has SwiGLU/GeGLU gating but never the base activation functions. | F | `gelu-silu.md` |
| ✅ | **Residual / Skip Connections** | y = x + F(x); the identity shortcut that makes deep nets trainable and defines the residual stream — referenced everywhere but never carded. | F | `residual-skip-connections.md` |
| ✅ | **Softmax Bottleneck & Logit Cap / Final-Layer Tying** | The rank limit of a softmax over a tied embedding and tricks (logit soft-capping, untied heads) that recur in modern LM design. | C | `softmax-bottleneck-logit-cap-final-layer-tying.md` |
| ✅ | **Cosine / Temperature in Contrastive & Attention Logits** | The 1/√d_k attention scaling and learned logit temperatures; an atomic numerical-stability concept distinct from softmax itself. | F | `cosine-temperature-in-contrastive-attention.md` |
| ✅ | **Multi-Token Prediction (MTP)** | Training/decoding heads that predict several future tokens at once (DeepSeek-V3, Medusa-style); doubles as a self-speculation draft. | C | `multi-token-prediction.md` |
| ✅ | **Mixture-of-Depths / Dynamic Compute Routing** | Letting tokens skip layers via a router to spend compute adaptively; a recurring efficiency primitive alongside MoE. | C | `mixture-of-depths-dynamic-compute-routing.md` |

## Attention Alternatives & Sequence Models
| Status | Concept | One-liner | Tier | Brick |
|--------|---------|-----------|:----:|-------|
| ✅ | **Linear Attention (Kernel-Feature / Associative Form)** | Replace softmax(QKᵀ)V with φ(Q)(φ(K)ᵀV) so attention becomes an associative sum with O(n) cost and a constant-size recurrent outer-product state instead of a growing KV cache. | F | `linear-attention.md` |
| ✅ | **Linear-Time-Invariant SSM (S4 / HiPPO / DPLR)** | Continuous-time linear recurrence x'=Ax+Bu, y=Cx discretized to a sequence model, A initialized via HiPPO and stabilized via diagonal (S4D) or diagonal-plus-low-rank structure for well-conditioned long-range memory. | F | `linear-time-invariant-ssm.md` |
| ✅ | **Selective State-Space Models / Mamba** | SSMs whose A/B/C/Δ parameters are made input-dependent (data-controlled), giving the recurrence content-based gating to selectively remember or ignore tokens — the innovation that closed the quality gap with attention. | C | `selective-state-space-models-mamba.md` |
| ✅ | **State-Space Duality (SSD / Mamba-2)** | Framework showing selective SSMs and a masked form of linear attention are two views of the same structured (semiseparable) matrix operator, letting Mamba-2 run as tensor-core matmuls. | C | `state-space-duality.md` |
| ✅ | **Recurrence-Convolution-Scan Duality** | Sub-quadratic layers admit an O(L) sequential recurrence for inference and an equivalent parallelizable form (global convolution or associative scan) for training — the trick behind S4 FFT, Mamba scan, and chunked linear attention. | F | `recurrence-convolution-scan-duality.md` |
| ✅ | **Hardware-Aware Parallel Scan** | A work-efficient associative (Blelloch) scan fused into a CUDA kernel that keeps SSM states in SRAM, making the selective non-convolutional recurrence fast on GPUs. | C | `hardware-aware-parallel-scan.md` |
| ✅ | **Chunked / Chunkwise-Parallel Form** | Split the sequence into chunks, compute exact attention within each and pass a summarized recurrent state between them, blending quadratic-local and linear-global compute for tensor-core efficiency (FlashLinearAttention). | C | `chunked-chunkwise-parallel-form.md` |
| ✅ | **Gated Linear Attention & Data-Dependent Decay** | Augment linear attention/SSMs with a (often data-dependent) multiplicative forget/decay gate controlling how fast old memory is overwritten — the axis distinguishing GLA, Mamba's Δ, HGRN, and RetNet's fixed γ. | C | `gated-linear-attention-data-dependent-decay.md` |
| ✅ | **Delta Rule / Fast-Weight Update (DeltaNet)** | Update the recurrent KV-state with an error-correcting delta-rule write S ← S(I−βkkᵀ)+βvkᵀ instead of pure additive accumulation, letting linear-attention models overwrite stored associations. | C | `delta-rule-fast-weight-update.md` |
| ✅ | **Test-Time Training / Expressive-State Memory (TTT, Titans)** | Treat the recurrent state as a small learnable model (matrix or MLP) whose memory is updated by online gradient descent on incoming tokens — RNN hidden state reframed as gradient-based test-time learning. | E | `test-time-training-expressive-state-memory.md` |
| ✅ | **RWKV (Time-Mixing Recurrence)** | A fully recurrent attention-free architecture (RWKV-4 through RWKV-7) using token-shift channel-mix plus a WKV time-mix behaving like decaying linear attention, trainable in parallel yet inferring as a constant-state RNN. | C | `rwkv.md` |
| ✅ | **Long-Convolution Models (Hyena / H3)** | Replace attention with data-controlled gating of an implicitly-parameterized sub-quadratic global convolution (filter as long as the sequence), computed via FFT; H3 is the canonical 'why pure SSMs fail at recall' study. | C | `long-convolution-models.md` |
| ✅ | **Associative Recall & the Recall-State-Size Tradeoff** | MQAR key-value lookup is the diagnostic for whether a sub-quadratic model can store arbitrary in-context bindings; fixed-size state bounds perfect recall, trading KV-cache growth for a hard capacity ceiling. | C | `associative-recall-the-recall-state-size.md` |
| ✅ | **Hybrid Attention-SSM Architectures** | Interleave a few full-attention layers among many SSM/linear-attention layers (Jamba, Zamba, Samba, Nemotron-H) to recover exact recall and copying while keeping most of the model sub-quadratic. | C | `hybrid-attention-ssm-architectures.md` |
| ✅ | **Transformer-to-Recurrent Distillation / Linearization** | Convert a pretrained softmax-attention transformer into a linear-attention or SSM (SUPRA, MOHAWK, Mamba-in-Llama, LoLCATs) by initializing/fine-tuning recurrent layers to match the teacher, avoiding pretraining from scratch. | E | `transformer-to-recurrent-distillation.md` |
| ✅ | **Constant-Memory Autoregressive Inference (No KV Cache)** | The headline serving advantage of recurrent/SSM models: a fixed-size hidden state replaces the linearly-growing transformer KV cache, giving O(1) memory and per-token latency regardless of context length. | C | `constant-memory-autoregressive-inference.md` |
| ✅ | **Bidirectional / Multi-Directional SSM Scanning** | Adapt inherently-causal recurrences to vision/audio/spatial data via multi-directional or bidirectional state passes (Vision Mamba, VMamba cross-scan), solving the 1D-causal-order problem for non-sequential data. | C | `bidirectional-multi-directional-ssm-scanning.md` |

| ✅ | **Data Mixture / Domain Weighting (DoReMi, RegMix)** | Set sampling proportions across domains (web, code, math, books, multilingual) via proxy-model methods like DoReMi (Group DRO), DOGE, or regression-based RegMix to maximize downstream accuracy. | C | `data-mixture-domain-weighting.md` |

| ✅ | **Synthetic Data & Web Rephrasing (WRAP, Phi)** | Use LLMs to generate or rephrase pretraining text (WRAP rewriting, textbook-style generation, math/code synthesis) to improve quality and stretch limited real data; core to frontier corpora. | C | `synthetic-data-web-rephrasing.md` |
| ✅ | **Model Collapse / Curse of Recursion** | Recursive training on a model's own outputs progressively degrades tail behavior and diversity until useless; accumulating synthetic with real data bounds the error — the guardrail of the synthetic-data era. | C | `model-collapse-curse-of-recursion.md` |
| ✅ | **Annealing / Mid-Training High-Quality Phase** | A short final pretraining phase upweighting the highest-quality and benchmark-relevant data (code, math, instructions) while the LR decays; near-universal in Llama 3, OLMo, MiniCPM recipes. | C | `annealing-mid-training-high-quality-phase.md` |
| ✅ | **Pretraining Data Curriculum** | Ordering or phasing data through training (quality/difficulty ramp, domain phase-ins) rather than i.i.d. sampling, often coupled to concentrating high-quality data in the WSD decay phase. | C | `pretraining-data-curriculum.md` |
| ✅ | **Decontamination (Train-Test Overlap Removal)** | Detect and remove pretraining documents overlapping with eval benchmarks (n-gram / embedding / canary matching) to prevent inflated, leaked eval scores. | C | `decontamination.md` |
| ✅ | **Sequence Packing & Document Attention Masking** | Concatenate variable-length documents into fixed-length sequences to avoid padding waste, with intra-document masking so tokens don't attend across document boundaries. | F | `sequence-packing-document-attention-masking.md` |
| ✅ | **Teacher Forcing & Exposure Bias** | Training on ground-truth-prefix vs. model-generated-prefix; the train/inference mismatch underlying autoregressive LM behavior and a recurring failure-mode explanation. | F | `teacher-forcing-exposure-bias.md` |

## Scaling Laws & Compute Allocation
| Status | Concept | One-liner | Tier | Brick |
|--------|---------|-----------|:----:|-------|
| ✅ | **Neural Scaling Laws (Kaplan / Chinchilla)** | Loss falls as a power law in parameters N, data D, and compute C=6ND, with Chinchilla giving the compute-optimal N*-D* allocation (scale both roughly equally). | F | `scaling-laws.md` |
| ✅ | **Compute Budget Identity C ≈ 6ND** | Training FLOPs equal roughly six times parameters times tokens — the back-of-envelope behind every token budget, runtime estimate, and scaling-law fit. | F | `compute-budget-identity-c-6nd.md` |
| ✅ | **Inference-Optimal Over-Training** | Beyond Chinchilla: deliberately over-train a smaller model on far more tokens (hundreds:1) because lifetime inference cost dominates training cost; the default for deployed models. | C | `inference-optimal-over-training.md` |
| ✅ | **Emergent Abilities & the Mirage Critique** | Sharp capability jumps with scale, argued by Schaeffer et al. to be largely artifacts of discontinuous/nonlinear metrics rather than true phase transitions, reshaping how progress is measured. | C | `emergent-abilities-the-mirage-critique.md` |
| ✅ | **Capacity-Density & Capability Scaling** | Newer fits relate downstream capability (not just cross-entropy) to scale, including 'capacity density' arguments that effective capability per parameter rises over time. | E | `capacity-density-capability-scaling.md` |
| ✅ | **Scaling-Law Extrapolation & Brittleness** | Fitting power laws on small runs to predict large ones, with pitfalls where exponents shift with architecture, tokenizer, data quality, and irreducible-loss offsets (broken neural scaling laws). | C | `scaling-law-extrapolation-brittleness.md` |

## Optimization & Training Dynamics
| Status | Concept | One-liner | Tier | Brick |
|--------|---------|-----------|:----:|-------|
| ✅ | **AdamW** | Adam with decoupled weight decay (decay applied directly to weights, not folded into the gradient L2 term), the default optimizer and baseline every new optimizer is benchmarked against. | F | `adamw.md` |
| ✅ | **Muon Optimizer** | Momentum SGD whose update matrix is orthogonalized via Newton-Schulz iteration (approximate per-layer spectral/whitening step), giving Adam-level or better loss at lower wall-clock for 2D weights. | C | `muon-optimizer.md` |
| ✅ | **Shampoo / SOAP (Second-Order Preconditioners)** | Adaptive optimizers using Kronecker-factored preconditioners over weight matrices; SOAP runs Adam in Shampoo's eigenbasis to cut overhead — the heavyweight 'is second-order worth it' comparison point. | C | `shampoo-soap.md` |
| ✅ | **Adam Hyperparameters (betas, epsilon, bias correction)** | The epsilon, momentum/variance decay rates, and 1−βᵗ bias-correction that set Adam's per-coordinate adaptive step; large β2 and epsilon are recurring culprits in instability and reproducibility. | F | `adam-hyperparameters.md` |
| ✅ | **maximal update parameterization (muP)** | Width-aware scaling of init variances and per-layer learning rates (Tensor Programs) keeping the network in the feature-learning regime so optimal HPs transfer from a tiny proxy to the full run. | C | `maximal-update-parameterization.md` |
| ✅ | **Warmup-Stable-Decay (WSD) Schedule** | Three-phase LR schedule (warmup, long constant plateau, short fast decay) that decouples LR from a fixed step count, enabling checkpoint reuse and compute-agnostic continuable training. | C | `warmup-stable-decay-schedule.md` |
| ✅ | **Learning-Rate Warmup** | Ramping LR from ~0 over the first steps to avoid early instability from large/poorly-conditioned updates and to let Adam's second-moment estimates warm up; tames early sharpness. | F | `learning-rate-warmup.md` |
| ✅ | **Cosine LR Decay** | Annealing LR along a cosine curve to a small floor over a pre-committed horizon, classically tied to Chinchilla compute-optimal training; the baseline WSD is compared against. | F | `cosine-lr-decay.md` |
| ✅ | **Decoupled Weight Decay** | Multiplicative per-step weight shrinkage independent of the loss gradient; under Adam it acts mainly as an implicit norm/effective-LR controller (the LR×wd product) rather than classic L2 overfitting prevention. | F | `decoupled-weight-decay.md` |
| ✅ | **Gradient Clipping** | Rescale the gradient (typically by global L2 norm) to a threshold to cap update magnitude and prevent divergence from rare large gradients; the standard guardrail in every large run. | F | `gradient-clipping.md` |
| ✅ | **Loss Spikes & Training Instability** | Sudden loss divergences at scale, traced to large attention logits, exploding output norms, bf16 precision, or bad data shards; documented with mitigations in every large-model tech report. | C | `loss-spikes-training-instability.md` |
| ✅ | **Z-Loss & Logit Stabilization** | Auxiliary regularizers (router/output z-loss, attention-logit soft-capping, embedding scaling) that keep softmax logits bounded to prevent divergence and loss spikes during large-scale pretraining. | C | `z-loss-logit-stabilization.md` |
| ✅ | **Edge of Stability** | The regime where the loss-Hessian's top eigenvalue (sharpness) hovers just above the 2/LR threshold and the loss decreases non-monotonically yet stably, where classical descent theory forbids training. | C | `edge-of-stability.md` |
| ✅ | **Sharpness-Aware Minimization (SAM) & Flat Minima** | Flatter minima tend to generalize better; SAM minimizes worst-case loss in a neighborhood via an ascent-then-descent step to bias training toward flat solutions at ~2x cost. | F | `sharpness-aware-minimization-flat-minima.md` |
| ✅ | **Critical Batch Size & Gradient Noise Scale** | The largest batch that still improves loss per token, predictable from the gradient signal-to-noise ratio; it grows during training, driving batch-size warmup and joint LR-batch tuning. | C | `critical-batch-size-gradient-noise-scale.md` |
| ✅ | **LR-Batch-Size Coupling (Linear / Sqrt Scaling)** | LR must scale with batch size (linear or square-root) to preserve optimization dynamics; the core relation governing data-parallel and large-batch training. | F | `lr-batch-size-coupling.md` |
| ✅ | **Initialization & Residual/Depth Scaling** | Choosing init variances and residual-branch downscaling (1/√depth, DeepNet/Fixup) so forward activations and backward gradients stay O(1) across depth at step zero, enabling stable deep training. | F | `initialization-residual-depth-scaling.md` |
| ✅ | **Effective LR & Norm-Growth Dynamics** | Under normalization + weight decay the relevant quantity is an effective LR set by the LR/weight-norm ratio, which evolves to a rotational equilibrium — why raw LR alone is misleading. | C | `effective-lr-norm-growth-dynamics.md` |
| ✅ | **Low-Precision Optimizer States & Stochastic Rounding** | Store optimizer moments/master weights in 8-bit/fp8 and use stochastic rounding for bf16 updates to cut memory and bandwidth while preserving convergence (8-bit Adam). | E | `low-precision-optimizer-states-stochastic.md` |
| ✅ | **Hyperparameter Scaling Laws (LR / batch / wd)** | Fitted power laws giving optimal LR, weight decay, and batch size as functions of model size and tokens, so HPs are predicted rather than swept (DeepSeek, MiniCPM, Step-law). | E | `hyperparameter-scaling-laws.md` |
| ✅ | **Implicit Bias of SGD** | (S)GD without explicit penalties is biased toward low-complexity solutions (max-margin / minimum-norm interpolators), the leading explanation for benign overfitting in overparameterized models. | F | `implicit-bias.md` |
| ✅ | **Grokking** | Delayed generalization: a network memorizes the training set then, with continued training, abruptly generalizes on held-out data — a testbed linking memorization, weight decay, and emergent circuits. | C | `grokking.md` |
| ✅ | **Adam Update Rule (the m/v EMA equations)** | The actual moment-estimate update θ ← θ − η·m̂/(√v̂+ε); the list has 'Adam hyperparameters' and 'AdamW' but never the core update itself. | F | `adam-update-rule.md` |
| ✅ | **Dropout** | Randomly zero activations at train time as stochastic regularization; still ubiquitous (attention/residual dropout, MC-dropout) and a constant reference point. | F | `dropout.md` |
| ✅ | **Label Smoothing** | Soften one-hot targets toward uniform to curb overconfidence; standard in LM/vision training and directly tied to calibration discussions. | F | `label-smoothing.md` |
| ✅ | **Weight Averaging / EMA & Model Soups** | Averaging weights across steps (EMA) or across fine-tuned checkpoints (soups); a cheap, recurrent generalization and stability trick. | F | `weight-averaging-ema-model-soups.md` |
| ✅ | **Muon / Spectral-Norm & Newton-Schulz Orthogonalization** | The orthogonalized-momentum update math (Newton-Schulz iteration) underlying Muon; an atomic primitive separate from the optimizer entry. | E | `muon-spectral-norm-newton-schulz.md` |
| ✅ | **Fisher Information & Natural Gradient** | Curvature of the log-likelihood; underlies natural-gradient/K-FAC, EWC continual learning, and the geometry behind TRPO/muP intuitions. | F | `fisher-information-natural-gradient.md` |

## Learning Theory & Generalization
| Status | Concept | One-liner | Tier | Brick |
|--------|---------|-----------|:----:|-------|
| ✅ | **Bias-Variance Tradeoff** | Decomposition of generalization error into bias (underfitting) and variance (overfitting); the classical U-shaped intuition that overparameterization later breaks. | F | `bias-variance.md` |
| ✅ | **Double Descent** | Test error rises to a peak at the interpolation threshold (capacity ≈ dataset size) then descends again in the overparameterized regime, contradicting the classical bias-variance curve. | F | `double-descent.md` |
| ✅ | **Neural Tangent Kernel (NTK) / Lazy Regime** | In the infinite-width limit, training behaves like kernel regression with a fixed kernel, making the network a linearized model with closed-form dynamics — the baseline for feature-learning contrasts. | F | `ntk.md` |
| ✅ | **Feature Learning vs Lazy Training** | Whether internal representations actually move (rich/feature-learning) or stay frozen (lazy/kernel), governed by parameterization and LR scaling; explains why real nets beat their NTK. | C | `feature-learning-vs-lazy-training.md` |
| ✅ | **PAC-Bayes & Compression Bounds** | Non-vacuous generalization guarantees from posterior-vs-prior divergence (PAC-Bayes) or network compressibility — the only family of bounds numerically meaningful for deep nets. | F | `pac-bayes.md` |
| ✅ | **Information Bottleneck** | View learning as compressing inputs into a representation that retains label-relevant information while discarding the rest, formalized via the I(X;T)−βI(T;Y) tradeoff. | F | `information-bottleneck.md` |
| ✅ | **Memorization vs Generalization** | Models provably memorize verbatim training data (extractable, especially duplicated/rare examples), distinct from learning generalizing structure, with privacy and copyright stakes. | C | `memorization-vs-generalization.md` |
| ✅ | **In-Context Learning as Implicit Optimization** | The view that attention performs gradient-descent/meta-learning over the prompt; a constant theoretical reference for emergent few-shot ability. | C | `in-context-learning.md` |

## Post-Training & RL Alignment
| Status | Concept | One-liner | Tier | Brick |
|--------|---------|-----------|:----:|-------|
| ✅ | **SFT / Instruction Tuning** | Supervised fine-tuning on (instruction, response) demonstrations via next-token cross-entropy to teach format and behavior; stage zero of every post-training pipeline and the reference policy the KL anchors to. | F | `sft-instruction-tuning.md` |

## Coverage critic notes
> The master list is unusually strong on 2024-2025 frontier architecture, post-training RL, inference serving, and interpretability — these are near-exhaustive and slightly over-represented (e.g. the attention-alternatives/SSM section is very deep, the SAE section very granular). The real blind spots are in two directions. (1) Classic-but-still-recurrent foundations that the advanced cards silently depend on: backprop, the Adam update itself, BatchNorm, Dropout, GELU/SiLU, residual connections, decoding/sampling strategies, teacher forcing, Gumbel-softmax/STE, label smoothing, EMA/model soups, GAE, importance sampling, and core eval primitives (ROC/AUC, bootstrap CIs, perplexity/bits-per-byte). These are 'a reviewer would ask why this isn't here' gaps. (2) Hardware-numerics and a few late-2025/2026 items: floating-point formats (bf16/fp16), MXFP/NVFP4 microscaling, Hadamard-rotation quantization, online-softmax, ring attention, CUDA graphs, multi-token prediction, async RL rollouts, and long-context eval (RULER/NIAH). Causal ML is thin relative to its own framing — frontdoor/mediation, DML, and propensity/IPW are conspicuously missing given backdoor and IV are present. I capped suggestions at 41 high-confidence atomic cards and deliberately excluded subfields, products, and single papers; a few (Muon Newton-Schulz, async RL infra) sit adjacent to existing entries but are distinct enough atomic primitives to merit their own card. Recommend prioritizing the foundational tier first — those are the highest-traffic lookups and the most embarrassing to lack.
