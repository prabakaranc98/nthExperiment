# Transformers, Diffusions, Flows, Graph Neural Networks

The four dominant architectural families in modern deep learning. This seminar goes deep on each — not just how they work but *why* they work, their limits, and how they connect.

## Focus Areas
- Transformers: attention mechanics, positional encoding, variants (linear, sparse, state-space)
- Diffusion models: score matching, DDPM, DDIM, flow matching
- Normalizing flows: change of variables, continuous flows (CNF, FFJORD)
- Graph neural networks: message passing, spectral vs. spatial, expressiveness limits
- Cross-architecture connections (e.g., diffusion as a GNN, transformers on graphs)
