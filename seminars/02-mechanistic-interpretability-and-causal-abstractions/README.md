# Mechanistic Interpretability and Causal Abstractions

What are neural networks actually computing? This seminar dissects the internal mechanisms of transformers and other models — circuits, features, attention patterns — and connects this to causal abstraction theory.

## Focus Areas
- Circuits: identifying minimal computational subgraphs
- Superposition hypothesis and sparse autoencoders (SAEs)
- Induction heads, indirect object identification, and algorithmic tasks
- Causal abstraction and interchange interventions
- Activation patching and causal tracing
- Probing classifiers and linear representation hypothesis
- From mechanistic findings to alignment implications
