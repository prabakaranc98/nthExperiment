# World Models

How can a system build an internal model of reality that supports prediction, planning, and imagination? This seminar covers the theory, architectures, and open questions in world modeling.

## Focus Areas
- Definition and taxonomy: what is a world model?
- Latent variable models: VAEs, VQ-VAE, discrete representations
- Recurrent world models: RSSM, Dreamer, PlaNet
- Transformers as world models: GAIA, Sora, VideoGPT
- World models for planning: MCTS + learned dynamics
- Grounded world models: connecting language to environment models
- Evaluation: how do you know a world model is good?
