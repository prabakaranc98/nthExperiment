# Continual Learning and Memory Models

How do systems learn without forgetting? This seminar covers catastrophic forgetting, lifelong learning, memory architectures (external and internal), and the emerging convergence with modern large models.

## Focus Areas
- Catastrophic forgetting and the stability-plasticity dilemma
- Regularization methods: EWC, SI, online EWC
- Replay methods: experience replay, generative replay
- Architecture-based approaches: PackNet, progressive nets
- Memory-augmented networks: NTM, DNC, Hopfield networks
- Continual learning in the era of LLMs
- Meta-learning connections (MAML, prototypical networks)
