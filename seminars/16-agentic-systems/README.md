# Agentic Systems

LLMs that act — using tools, planning across multiple steps, coordinating with other agents, and operating in long-horizon tasks. This seminar covers the architectures, failure modes, and open research problems.

## Focus Areas
- Tool use and function calling: mechanics and reliability
- ReAct, Reflexion, and chain-of-thought action loops
- Memory systems: in-context, external, episodic, semantic
- Multi-agent coordination: competition, cooperation, emergent norms
- Long-horizon planning and task decomposition
- Evaluation: how do you benchmark an agent?
- Safety in agentic contexts: irreversibility, authorization, oversight
