# Applied Machine / Deep Learning

Where theory meets practice — systems that work in the real world across structured data, time series, tabular settings, and domain-specific applications. Focus on what actually generalizes.

## Focus Areas
- Gradient boosting and when deep learning doesn't beat trees
- Time series: forecasting, anomaly detection, representation
- Tabular deep learning: embeddings, attention over features
- Transfer learning and fine-tuning in practice
- Label noise, class imbalance, and real-world data issues
- Production ML: serving, monitoring, distribution shift detection
- Experiment design and evaluation methodology
