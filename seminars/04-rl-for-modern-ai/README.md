# RL for Modern AI

Reinforcement learning as the substrate for reasoning, planning, and learning to act — from the classical foundations to its role in post-training LLMs, MCTS-based reasoning, and multi-agent systems.

## Focus Areas
- Policy gradient methods: REINFORCE, PPO, GRPO
- Value-based methods: DQN, TD-learning, Q-learning
- Model-based RL and planning (Dreamer, MuZero)
- RL + LLMs: RLHF, process reward models, STaR, RLVR
- Multi-agent RL: cooperation, competition, emergent behavior
- RL for reasoning: Monte Carlo Tree Search, AlphaProof
- Reward hacking, specification gaming, and alignment
