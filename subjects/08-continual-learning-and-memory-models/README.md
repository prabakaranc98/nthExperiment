# Continual Learning and Memory Models

> I am deeply curious about how intelligent systems can keep learning without losing what they already know — and how memory, in both biological and artificial systems, makes knowledge accumulation possible over time.

## Core Questions
- Why do neural networks catastrophically forget, and what does that reveal about how they learn?
- What is the right architecture for a system that must keep learning?
- How do biological memory systems (hippocampus, cortex) inform artificial ones?
- Can memory be made differentiable, addressable, and generative?
