# Representation Learning, Generative AI and Reinforcement Learning

> I am deeply curious about how systems learn to encode the structure of the world — and how that learned structure powers both generation (creating new things) and decision-making (acting in the world). Representation is the common thread.

## Core Questions
- What makes a representation useful — for generation, for control, for generalization?
- How do generative models and RL share the same underlying problem of modeling the world?
- Can a single learned representation serve both predictive and generative purposes?
- What is the right inductive bias for each modality?
