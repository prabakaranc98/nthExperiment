# Frontier Systems for AI

> I am deeply curious about how the most capable AI systems actually work — not just using them, but understanding the mechanics: how reasoning emerges, what world models are doing, why scale works, and where the real limits are.

## Core Questions
- What is a frontier model actually computing?
- How does reasoning emerge from next-token prediction?
- What can these systems genuinely not do, and why?
- What does interpretability reveal about what's inside?
