# Experiments

A log of things built, tested, reproduced, and broken — spawned from seminar reading or independent curiosity.

Each experiment lives in its own folder. Use `_templates/experiment.md` to start one.

## How to Start One

```
experiments/
└── 001-name-of-experiment/
    ├── experiment.md    ← copy from _templates/experiment.md
    ├── log.md           ← running notes as you work
    └── reflection.md    ← fill when done
```

Types: `investigate` · `replicate` · `build` · `extend` · `reflect`
